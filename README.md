# Проект Банковский виджет

## Описание

Проект Банковский виджет - это домашнее задание, выплняемое в несколько этапов для закрепеления навыков разработки на python с использованияем GIT

## Установка

Клонируйте репозиторий 
```
git clone https://github.com/vmrmozg138/HW_LINT_V2
```

## Текущее состояние проекта

На данный момент реализовано несколько модулей. Функционал для маскировки номеров карт и счетов был создан в предыдущих этапах домашнего задания.

К **07.06.2026** был создан модуль processing, в котором реализованы фильтрация и сортировка списка словарей. Все изменения влиты в удаленный репозиторий, в ветку feature_1

К **21.06.2026** был добавлен модуль generators, в нем реализованы фильтрация транзакций по валюте, функция для выдачи только описаний транзакций и функция для генераций номеров банковских карт

К **28.06.2026** добавлен модуль decorators с логированием выполнения функции

К **05.07.2026** добавлен модуль utils для считывания транзакций из json файла и конвертирования стоимости транзакции если валюта не рубль(при использовании функционала добавленного модуля external_api)

К **06.07.2026** добавлено логирование для модулей utils и masks

К **08.07.2026** добавлены считывания информации из csv и excel с логированием функций, а также добавил функцию для приведения file_name в file_path

Добавлены модули для поиска операций по части описания и подсчета и группировки операций по категориям. Логика сведена в модуль main

### Тестирование 

К **14.06.2026** было добавлено покрытие тестами всех модулей(masks.py, processing.py, widget.py). Также представлена информация о покрытии тестами, её можно найти в htmlcov/index.html
К **21.06.2026** также было добавлено тестирование для модуля generators
К **28.06.2026** добавлено тестирование дя декоратора log. Тестируется вывод в консоль для случая, когда функция отрабатывает без ошибок
